Gestión de Encuestas

Nuevos Módulos Analíticos

El sistema ha evolucionado para ofrecerte inteligencia de datos y control territorial total en sus versiones más recientes.

📊 Dashboard Interactivo (v1.2.0)

Nuevo panel de control OWL con integración de Chart.js. Visualiza métricas en tiempo real, KPIs de impacto social (personas beneficiadas, demografía vulnerable) y analiza el estado de tus encuestas de un vistazo rápido.

🗺️ Mapa Global Offline (v1.3.0)

Vista cartográfica interactiva 100% nativa y sin dependencias de internet. Observa la geolocalización exacta de cada proyecto fotovoltaico sobre el territorio, agrupa por comunidades y accede a formularios desde pines inteligentes.
